# 运维流水线 A+B：对齐蓝鲸标准运维（SOPS）

**Goal:** 在现有 Vue Flow 能力上，把「流程模板 / 任务 / 画布 / 选主机」做成接近蓝鲸标准运维的工作台体验，并补齐关键节点与执行态能力。  
**Not goal:** 复刻蓝鲸权限体系、公共流程市场、完整 CMDB 拓扑（可后续迭代）。

## Baseline（已有）

- 模板表 `/flows`、任务表 `/flows/tasks`、启动填参、定时调度
- 画布：左节点库 + 中 DAG + 右配置
- 节点：script / file_transfer / job_plan / manual / condition / parallel / join / sub_process
- 选主机：`HostSelector` 静态 / 动态 / 解析 + 右侧预览

## Gaps → A+B

### A — 体验对齐

1. **模板工作台壳**：列表支持「新建任务」主路径；可选卡片/表切换；命名贴近 SOPS（流程 / 任务）。
2. **执行态画布**：`/flows/runs/:id` 用 Vue Flow 展示节点状态（成功/失败/运行中/暂停），替代纯列表拓扑；保留侧栏详情与人工确认。
3. **启动向导**：启动弹窗更接近「新建任务」：任务名 → 全局变量 → 确认执行。
4. **选主机蓝鲸化**（QuickExecute / 作业执行等共用 `HostSelector`）：
   - 左拓扑分组（展开可见主机 + 勾选态）
   - 中主机表**必须有多选框**；点分组过滤列表
   - 右结果预览（已有，保持）

### B — 能力补齐

1. **审批味**：`manual` 产品文案/面板对齐「人工审批」，通过/拒绝原因。
2. **子流程 / 并行汇聚**：配置面板与校验提示补全（能力已有则重在 UX）。
3. **任务操作**：节点重试 / 跳过 / 强制失败（已有入口则统一到画布节点菜单）。
4. （可选后续）通知、公共模板目录 — 不进本轮必做。

## Constraints

- 继续 Naive UI + Lucide + Vue Flow；不引 Arco
- 不破坏现有 `flowApi` 合同；UI 优先，后端缺口单列
- `HostSelector` 为共享组件，改完需覆盖快速执行、执行方案执行等入口

## Suggested task order

1. HostSelector 静态多选 + 分组下展示已选主机（本轮）
2. 执行态画布（run-detail）
3. 模板列表「新建任务」主路径 + 启动向导文案
4. manual/审批与节点菜单打磨
5. 回归：flows 列表/编辑/启动/任务/运行；QuickExecute 选主机

## Acceptance（A+B 最小可验收）

- [x] 静态选主机：表头有多选框；勾选后右侧预览有 IP；展开分组能看到已选主机
- [x] 点分组可过滤中间主机列表，并显示「已选 x」
- [x] 运行详情是带状态的画布，不只是文章列表
- [x] 模板侧可「新建任务」进入启动填参
- [x] 人工节点在暂停时可审批通过/拒绝
- [x] 子流程配置面板可选手动输入 JSON；运行态可跳转子任务
- [x] 模板列表默认表格，可选卡片视图
- [x] 运行画布节点可直接重试 / 跳过 / 审批通过拒绝
- [x] 并行 / 汇聚网关有独立配置说明
- [x] 审批拒绝会取消同流程其它活跃节点
- [x] HostSelector 空选择不可确认
- [x] 非人工节点可强制失败（画布 + 列表），并按失败策略处理
